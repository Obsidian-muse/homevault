# HomeVault

Track electronics, furniture, appliances, and personal belongings in one place.

## Stack
Next.js 15 (App Router) · TypeScript · Tailwind CSS · Shadcn UI · PostgreSQL · Prisma · NextAuth.js · Cloudinary

## Setup
1. `npm install`
2. Copy `.env.example` to `.env` and fill in your values.
3. `npx prisma generate`
4. `npx prisma migrate dev --name init`
5. `npm run dev`
